# Security Policy

If you discover a security issue, please bring it to our attention right away!

## Reporting a Vulnerability

Report suspected vulnerabilities privately using **Report a vulnerability** in the affected repository's Security tab. If that option is unavailable, use the support contact shown on [sugar.win](https://sugar.win). Include the affected version, impact and a minimal reproduction. Keep sensitive details out of public issues and pull requests.

## Supported Versions

Project versions that are currently being supported with security updates vary per project. Please see specific project repositories for details. If nothing is specified, only the latest major versions are supported.
